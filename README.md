# GeoSphere 🌍

Interactive Geopolitical Intelligence Dashboard built using Flask, JavaScript, HTML/CSS, and APIs.

---

## Features

- Interactive world map
- NATO / BRICS / SCO / QUAD visualization
- Country intelligence panel
- Alliance information pages
- Search functionality
- Real-time geopolitical news
- Dark intelligence dashboard UI

---

## Tech Stack

- Python
- Flask
- JavaScript
- HTML/CSS
- jsVectorMap
- REST Countries API
- News API

---

## Installation

```bash
pip install -r requirements.txt
python app.py
```
